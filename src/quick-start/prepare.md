# 准备工作

在安装之前，强烈建议您先安装所需要的字体资源。

- [HarmonyOS Sans <span class="iconify" data-icon="material-symbols:download-rounded"></span>](https://developer.huawei.com/images/download/general/HarmonyOS-Sans.zip)
- [MiSans <span class="iconify" data-icon="material-symbols:download-rounded"></span>](https://hyperos.mi.com/font/download)

> 当然，您也可以跳过字体安装继续后续步骤，但可能会遇到字体问题。
