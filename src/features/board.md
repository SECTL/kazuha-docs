# 板中板

板中板（Board-in-Board）是一个独立的自由书写画板功能，可以在 PPT 放映过程中随时打开，用于临时书写、绘图或标注。

## 功能概述

板中板提供了一个独立的浮动窗口，具有以下特点：
- **自由书写**: 不受 PPT 内容限制，自由绘制
- **透明背景**: 可选择透明或纯色背景
- **独立窗口**: 不影响 PPT 放映，可随时最小化
- **画笔工具**: 多种颜色和粗细可选
- **橡皮擦**: 精确擦除或整体清除

## 使用方法

### 打开板中板

1. **通过工具栏**: 点击工具栏上的「板中板」按钮
2. **通过 API**: 主题开发者可调用 `bridge.toggleBoard()`
3. **快捷键**: 可在设置中配置快捷键

### 画笔工具

**选择画笔**
- 点击画笔图标或按 `P` 键
- 支持 20 种主题色 + 10 种标准色
- 粗细可调（1-18 像素）

**颜色选择**
- 点击颜色面板选择画笔颜色
- 支持深色/浅色模式自动适配
- 记忆上次使用的颜色

### 橡皮擦工具

**两种擦除模式**
1. **点擦除**: 擦除鼠标点击处的笔画
2. **笔画擦除**: 擦除整条笔画

**调整橡皮擦大小**
- 橡皮擦粗细可调（8-40 像素）
- 大橡皮擦适合快速清除大面积内容

### 清屏

- 点击「清空」按钮或按 `C` 键
- 清除所有笔迹
- **注意**: 清除后无法撤销

### 背景设置

**背景颜色**
- 默认跟随系统主题（深色/浅色）
- 可手动设置为纯白、纯黑或自定义颜色
- 透明背景模式（透过画板看到 PPT 内容）

### 关闭板中板

- 点击关闭按钮或按 `Esc` 键
- **保留笔迹提示**: 关闭时会询问是否保留当前笔迹
  - 保留: 下次打开时恢复当前内容
  - 不保留: 清空画板并关闭

## 配置选项

在「设置 → 工具栏」中可以配置：

| 选项 | 说明 | 默认值 |
|------|------|--------|
| 显示板中板按钮 | 在工具栏显示/隐藏板中板按钮 | 开启 |
| 默认画笔颜色 | 设置打开时的默认画笔颜色 | 主题色 |
| 默认画笔粗细 | 设置打开时的默认画笔粗细 | 3 像素 |

## 与 PPT 墨迹的区别

| 特性 | 板中板 | PPT 墨迹 |
|------|--------|----------|
| 保存位置 | 临时内存（可保留到下次） | PPT 文件内 |
| 影响 PPT | 不影响 | 成为 PPT 一部分 |
| 背景 | 可透明/纯色 | 依赖 PPT 背景 |
| 范围 | 自由窗口 | 单页幻灯片 |
| 持久性 | 关闭后默认清除 | 保存到 PPT |

## 使用场景

1. **临时演算**: 在讲解时进行数学计算或逻辑推演
2. **补充说明**: 在 PPT 内容之外添加额外注释
3. **互动问答**: 在讨论环节记录观点或答案
4. **思维导图**: 边讲边绘制思维导图
5. **标记重点**: 在复杂图表上圈出重要部分

## 主题开发 API

如果你是主题开发者，可以通过以下 API 控制板中板：

```javascript
// 打开/关闭板中板（切换）
bridge.toggleBoard();

// 监听板中板状态变化
window.updateConfig = function(config) {
    // config 包含板中板相关配置
};
```

## 技巧与建议

1. **双屏演示**: 在主屏幕放映 PPT，在副屏幕打开板中板，方便随时参考
2. **预设颜色**: 在设置中预设常用颜色，提高书写效率
3. **分层使用**: 复杂讲解时，先用板中板打草稿，确认后再写到 PPT 上
4. **配合聚光灯**: 使用聚光灯聚焦到 PPT 内容，同时在板中板书写
5. **定期清屏**: 内容过多时及时清屏，保持清晰

## 故障排除

**板中板无法打开**
- 检查设置中是否启用了板中板按钮
- 确认工具栏设置中「显示板中板」已勾选

**画笔无法使用**
- 确保已选择画笔工具（不是橡皮擦）
- 检查是否选择了有效的颜色

**笔迹无法保留**
- 关闭时选择「保留笔迹」
- 完全退出 Luminalium 后笔迹会丢失（设计如此）

**画板位置不对**
- 拖动标题栏移动窗口位置
- 调整窗口大小以适应需要
