# 应用启动器

应用启动器是工具栏的一个扩展功能，允许你将常用的应用程序、文件或快捷方式固定到工具栏上，方便在演示过程中快速启动。

## 功能概述

应用启动器位于工具栏中，可以：
- 固定常用应用程序
- 固定常用文件（PPT、PDF、图片等）
- 固定文件夹快捷方式
- 快速启动外部程序

## 使用方法

### 添加应用到启动器

1. 打开 Luminalium 设置
2. 进入「工具栏」设置页面
3. 找到「固定应用」区域
4. 点击「添加」按钮
5. 选择要固定的应用程序或文件

### 从工具栏启动应用

1. 在 PPT 放映时，工具栏会自动显示
2. 点击工具栏上的应用图标
3. 应用将在后台启动

### 管理固定应用

- **排序**: 拖动应用图标调整顺序
- **删除**: 右键点击应用图标选择移除
- **编辑**: 右键点击修改应用路径或名称

## 支持的文件类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 应用程序 | .exe 可执行文件 | Chrome、记事本 |
| 文档 | PPT、PDF、Word | presentation.pptx |
| 图片 | JPG、PNG、SVG | diagram.png |
| 文件夹 | 目录快捷方式 | D:\\Documents |

## 配置选项

在设置 → 工具栏中，你可以：
- 启用/禁用应用启动器
- 设置显示的图标大小
- 调整图标间距
- 选择显示模式（图标/图标+文字）

## 使用建议

1. **常用软件**: 将演示中需要使用的软件（如浏览器、计算器）固定到启动器
2. **备用 PPT**: 固定备用演示文稿，以便在主演示出现问题时快速切换
3. **工具软件**: 固定截图工具、录屏软件等辅助工具
4. **不宜过多**: 建议固定 4-8 个最常用的应用，保持工具栏整洁

## 与工具栏的关系

应用启动器是工具栏的一部分：
- 遵循工具栏的位置设置（上/下/左/右）
- 响应工具栏的显示/隐藏状态
- 支持工具栏的透明度设置

## API 接口（主题开发）

如果你是主题开发者，可以通过以下 API 控制应用启动器：

```javascript
// 启动指定路径的应用
bridge.launchApp('C:\\Program Files\\App\\app.exe');
```

## 故障排除

**应用无法启动**
- 检查应用路径是否正确
- 确认应用文件是否存在
- 尝试以管理员权限运行 Luminalium

**图标不显示**
- 某些应用可能需要自定义图标
- 在设置中为该应用指定图标文件

**启动器不显示**
- 检查设置中是否启用了应用启动器
- 确认工具栏设置中「显示启动器」已勾选
