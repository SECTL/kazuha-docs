# 状态栏

状态栏显示在 PPT 放映界面的顶部或底部（取决于工具栏位置），提供系统状态信息和实用功能。

## 功能概述

状态栏是一个信息展示区域，显示：
- 当前时间
- 电池电量（笔记本）
- 系统音量
- 网络连接状态
- 音乐播放信息

## 显示内容

### 时间显示

**格式选项**
- 仅小时:分钟（如 14:30）
- 小时:分钟:秒（如 14:30:45）

**配置**
- 在「设置 → 悬浮窗」中启用/禁用
- 可选择是否显示秒数

### 电池电量

**显示内容**
- 电池图标 + 百分比（如 🔋 85%）
- 充电状态指示

**适用场景**
- 笔记本演示时监控电量
- 避免演示过程中电量不足

**配置**
- 在「设置 → 悬浮窗」中启用/禁用

### 音量显示

**显示内容**
- 音量图标 + 百分比（如 🔊 60%）
- 静音状态指示

**适用场景**
- 快速查看当前音量
- 避免演示时声音过大或过小

**配置**
- 在「设置 → 悬浮窗」中启用/禁用

### 网络状态

**显示内容**
- 网络连接状态图标
- 在线/离线指示

**适用场景**
- 确认网络连接正常
- 需要在线资源时检查网络

**配置**
- 在「设置 → 悬浮窗」中启用/禁用

### 音乐播放

**显示内容**
- 音乐图标
- 歌曲名称（如果支持）
- 播放进度（可选）

**适用场景**
- 演示间隙播放背景音乐
- 快速查看当前播放曲目

**配置**
- 在「设置 → 悬浮窗」中启用/禁用音乐显示
- 可选择是否显示播放进度

## 启用与禁用

### 显示状态栏

1. 打开 Luminalium 设置
2. 进入「悬浮窗」设置页面
3. 勾选「显示状态栏」
4. 分别勾选需要显示的项目（时间、电池、音量、网络、音乐）

### 隐藏状态栏

1. 在「悬浮窗」设置中取消勾选「显示状态栏」
2. 或单独取消勾选特定项目

## 位置与样式

**位置**
- 工具栏在顶部 → 状态栏在底部
- 工具栏在底部 → 状态栏在顶部
- 工具栏在左侧/右侧 → 状态栏在顶部

**样式**
- 跟随主题颜色
- 支持深色/浅色模式
- 透明度与工具栏同步（如果启用了同步透明度）

**图标风格**
- 使用系统图标风格
- 支持高 DPI 显示

## 配置选项

在「设置 → 悬浮窗」中：

| 选项 | 说明 | 默认值 |
|------|------|--------|
| 显示状态栏 | 总开关 | 开启 |
| 显示时间 | 显示当前时间 | 开启 |
| 显示秒数 | 时间是否包含秒 | 关闭 |
| 显示电池 | 显示电池电量 | 开启 |
| 显示音量 | 显示系统音量 | 关闭 |
| 显示网络 | 显示网络状态 | 关闭 |
| 显示音乐 | 显示音乐播放信息 | 关闭 |
| 显示播放进度 | 显示音乐播放进度 | 关闭 |

## 使用建议

1. **常规演示**: 建议开启时间和电池，监控演示进度和设备电量
2. **在线演示**: 额外开启网络状态，确保连接稳定
3. **背景音乐**: 开启音乐显示，方便控制背景音乐
4. **简洁模式**: 如果屏幕空间有限，可仅保留时间和电池

## 主题开发 API

如果你是主题开发者，可以通过以下 API 获取状态信息：

```javascript
// 接收系统状态更新
window.updateSystemStatus = function(data) {
    // data.battery_percent - 电池百分比
    // data.network_online - 网络是否在线
    // data.volume - 音量 (0-100)
    // data.smtc_status - 音乐播放状态
};
```

## 故障排除

**状态栏不显示**
- 检查设置中是否启用了状态栏
- 确认至少启用了一个显示项目（时间、电池等）
- 检查是否被其他窗口遮挡

**信息不更新**
- 状态栏每几秒刷新一次，属正常现象
- 如果长时间不更新，尝试重新启用该选项

**电池显示为 0%**
- 某些台式机可能没有电池，会显示 0% 或 N/A
- 这是正常行为，不影响功能使用

**音乐信息不显示**
- 确保系统正在播放音乐
- 某些音乐播放器可能不支持 SMTC 接口
- 尝试使用 Windows 自带的「音乐」应用
